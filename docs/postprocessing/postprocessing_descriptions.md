# USegment3D Consensus Fusion

> "u-Segment3D is a Python library to merge 2D slice-by-slice segmented 3D volumes in x-y, x-z, or y-z views into a single consensus 3D segmentation. u-Segment3D can use the probabilities and gradients directly predicted by popular existing Neural Network segmentation models such as Cellpose (Direct Method) or operates on the provided 2D segmentations directly (Indirect Method). u-Segment3D does not require all 3 views, any number can be used, nor do each view need be generated by the same algorithm. u-Segment3D also provides a number of postprocessing algorithms to recover missing features after obtaining the 3D segmentation. Therefore, it can also be used as a postprocessing module for 3D segmentations in general. Despite the name, the postprocessing and segmentation functions in u-Segment3D have 2D equivalents which can be used to enhance 2D segmentation too. Please see the tutorials."
> 
> — Source: [DanuserLab/u-segment3D](https://github.com/DanuserLab/u-segment3D)

AdaptFM integrates `u-Segment3D` to fuse 2D slice-by-slice predictions taken along multiple reference planes (XY, XZ, YZ) into a single, unified 3D consensus segmentation volume.

***To run USegment3D, your input directory must contain 2D plane prediction subfolders (e.g., `XY_planes`, `XZ_planes`, `YZ_planes`) containing matching TIFF filenames.***

USegment3D integrates into the rest of AdaptFM via the following workflow: first run the preprocessing function **Copy TIFF Image Data to 3 Plane Views** on your raw 3D volumes. Next, execute model inference or batch interactive segmentation across the generated plane subdirectories, saving the resulting prediction masks into a matching 2D Predictions Directory (shown below). The resulting predictions from these three folders can be combined with USegment3D. 

You may want to use USegment3D if you are unhappy with the Z-layer consistency of our annotation segmentation algorithms for generating image labels, or with CellposeSAM's/MicroSAM's inference which use their own 2d slice -> 3d volume algorithm.

## Input Directory Structure

A couple of important points about the USegment3D input and output structure:
- **Flexible Plane Support**: While processing all 3 plane views (`XY`, `XZ`, `YZ`) yields the highest consensus accuracy, `u-Segment3D` fully supports running with 1 or 2 planes if directories are missing or empty.
- **Filename Alignment Requirement**: Corresponding TIFF files across active plane directories **must** share identical file stems (e.g., `sample_001.tiff`) to be paired together during aggregation.

```text
2D Predictions Directory (Input)
├── XY_planes - 2D predictions along XY plane
│   ├── sample_001.tiff
│   ├── sample_002.tiff
│   └── ...
├── XZ_planes - 2D predictions along XZ plane (Optional)
│   ├── sample_001.tiff
│   ├── sample_002.tiff
│   └── ...
└── YZ_planes - 2D predictions along YZ plane (Optional)
    ├── sample_001.tiff
    ├── sample_002.tiff
    └── ...

3D Consensus Directory (Output)
├── sample_001.tiff - Fused 3D consensus volume
├── sample_002.tiff - Fused 3D consensus volume
└── ...
```

## How It Works

The tool aggregates multi-view predictions into a 3D volume using the following logic:

1. **Discover plane directories** - The script scans the input folder for `XY_planes/`, `YZ_planes/`, and `XZ_planes/`. Missing or empty directories issue warnings (`[PLANE MISSING WARNING]` / `[PLANE EMPTY WARNING]`) and populate empty placeholders (`[]`) to support reduced-dimension runs.
2. **Match filenames across active planes** - It pairs non-hidden TIFF files sharing identical file stems. If active plane folders exist but share zero common filenames, it raises a detailed `Plane Mismatch Error`.
3. **Validate prediction stack shape** - Loads each plane's prediction array and verifies that present views are 3D image stacks (`ndim == 3`).
4. **Determine 3D target shape** - Reconstructs the target 3D spatial shape (`img_xy_shape`) from whichever plane stack is available (automatically inverting transpose axes for XZ or YZ if XY is omitted).
5. **Execute indirect consensus fusion** - Configures distance transform parameters (`dtform_method = "edt"`) and runs `aggregate_2D_to_3D_segmentation_indirect_method()` across available plane arrays.
6. **Save fused 3D volumes** - Saves the aggregated 3D consensus segmentation mask as a single TIFF file (`<image_name>.tiff`) in the output directory.

# Convert uint8 TIFF Data to Binary Mask (0|1)

This utility converts object ID or multi-class segmentation masks into a unified binary mask. It is particularly useful when you have a mask with multiple distinct objects (e.g., cell instances labeled 1, 2, 3, etc.) or multiple classes, and you need to simplify it into a basic foreground vs. background format (1s and 0s).

***Importantly, this process requires your input images to be in `uint8` format. If your data is in a different format (like float), you must first convert the datatype to `uint8` to avoid processing errors.***

## How It Works

The conversion process applies the following steps to process your image data:

1. **Scan the input directory** - The tool identifies all `.tiff` or `.tif` files in your designated input folder.
2. **Validate data type** - It checks that each image is strictly formatted as a `uint8` array. If an image is not `uint8`, the process will stop and alert you to run a conversion first. 
3. **Binarize the mask** - The algorithm looks at every pixel in the image. Any pixel with a value greater than `0` (any foreground label) is converted to `1`. Pixels with a value of `0` (background) remain `0`.
4. **Save the output** - The newly created binary mask is saved into the output directory using the original filename.
