# USegment3D

> "u-Segment3D is a Python library to merge 2D slice-by-slice segmented 3D volumes in x-y, x-z, or y-z views into a single consensus 3D segmentation. u-Segment3D can use the probabilities and gradients directly predicted by popular existing Neural Network segmentation models such as Cellpose (Direct Method) or operates on the provided 2D segmentations directly (Indirect Method). u-Segment3D does not require all 3 views, any number can be used, nor do each view need be generated by the same algorithm. u-Segment3D also provides a number of postprocessing algorithms to recover missing features after obtaining the 3D segmentation. Therefore, it can also be used as a postprocessing module for 3D segmentations in general. Despite the name, the postprocessing and segmentation functions in u-Segment3D have 2D equivalents which can be used to enhance 2D segmentation too. Please see the tutorials."
> 
> — Source: [DanuserLab/u-segment3D](https://github.com/DanuserLab/u-segment3D)

AdaptFM integrates `u-Segment3D` to allow slice-by-slice 2D predictions along multiple reference planes (e.g., XY, XZ, YZ) to be fused into a single unified 3D segmentation without requiring full 3D neural network architectures.

## How It Works

1. **Directory Discovery & File Matching** – The tool scans three required subdirectories inside the designated input directory: `XY_planes/`, `YZ_planes/`, and `XZ_planes/`. It pairs non-hidden TIFF stack files (`.tif`/`.tiff`) that share identical filenames across all three subfolders.
2. **Dimension Validation** – Loads each plane's corresponding TIFF file as a 3D NumPy array stack and validates that all three views (`xy`, `yz`, `xz`) have 3 dimensions.
3. **Indirect Method Configuration** – Fetches default 2D-to-3D aggregation parameters from `segment3D.parameters` and updates the distance transform configuration (`dtform_method`) to use Euclidean Distance Transform (`edt`).
4. **Consensus Aggregation** – Calls `uSegment3D.aggregate_2D_to_3D_segmentation_indirect_method()` using the three orthogonal 2D segmentation stacks to construct a single aggregated 3D segmentation volume.
5. **Export** – Saves the resulting 3D segmentation array as a single TIFF volume (`<image_name>.tif`) in the output directory.
