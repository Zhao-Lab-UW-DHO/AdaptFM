# Customizing AdaptFM

AdaptFM is highly customizable. If you do not have programming experience and would like a new model, benchmark, or annotation algorithm create an 'issue ticket'. We're happy to add it for you. 

If you have experience programming and would like to add your own model or benchmark. Follow our [documentation on customizing AdaptFM](../customizing-adaptfm/index), and consider submitting a pull request. Pull request guidelines are found on the [contributing page](../customizing-adaptfm/contributing).
