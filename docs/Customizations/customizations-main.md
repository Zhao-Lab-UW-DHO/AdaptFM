# Customizing AdaptFM

AdaptFM is highly customizable. If you do not have programming experience and would like a new model, benchmark, or annotation algorithm create an 'issue ticket' . We're happy to add it for you. 

If you have programming experience and would like to add your own model or benchmark. Follow the instructions below for each module, and consider submitting a pull request.
