# AdaptFM

An interactive framework for annotating, training, running inference, and benchmarking 3D segmentation models. 

In AdaptFM you can:
- Test and benchmark 3D segmentation models on your data. We currently support CellposeSAM, MicroSAM, nnUNetv2, SAM-Med-3D, and SSVT a masked autoencoder pretrained on 180,000 3D organoid images.
- Interactively create 3D annotations using a number of segmentation algorithms, including using SAM2 for click-based segmentation
- Use those annotations to fine-tune/train models on your data
- Add new models or annotation algorithms
